# GPT 侧边栏 / GPT Sidebar

[English](README.en.md) · [数据与隐私](PRIVACY.md) · [许可证](LICENSE) · [第三方许可](THIRD_PARTY_NOTICES.md)

在 Microsoft Edge 侧栏中使用自己的 ChatGPT 账号聊天，支持右键选文、按需读取网页/PDF、图片与文件草稿、LaTeX 公式和 Markdown 导出。

**这是第三方个人项目，不是 OpenAI 或 Microsoft 官方产品。** 当前版本 **0.4.0**，可手动加载安装；商店审核和发行进度以 Partner Center 为准。

## 功能

- 紧凑侧栏：模型与支持的思考强度选择、12–20 px 字号、明暗主题、简体中文/English 界面。
- 历史对话：搜索、切换、重命名、删除与撤销、导出 Markdown。空白对话不进入历史；未发送草稿保留。
- 右键选文进入可编辑草稿，不自动发送。
- 联网按钮默认关闭；开启后模型可自主搜索、打开和查找公共网页，回答显示引用和默认折叠的来源列表，历史和 Markdown 导出保留来源。
- 按需读取当前网页或在线 PDF、截取当前网页可见区域。普通聊天不会自动读取资料。
- 粘贴图片、拖放和上传文件；支持 PNG/JPG/WebP、PDF 和文本类文件。每次最多 3 份、每份最多 20 MB。
- PDF 本地提取文字，最多 60 页/120000 字符；扫描版没有 OCR。图片最长边缩放至 2048 px。
- Markdown 和本地 KaTeX 公式渲染；导出使用 Obsidian 公式分隔符。
- 按用户明确的文件生成请求，创建可下载的文本文件。单文件上限可设为 1–5 MB；不执行文件，不生成 Word/PDF 等二进制文件。
- 流式回答可停止；中断不会自动重发。对话和授权保存在当前浏览器配置的本地扩展存储。

## 增强公共读取与资料快照（0.4.0）

设置 →「增强公共读取」→ 勾选「允许模型直接读取公共网页和 PDF」，在 Edge 的权限窗口中授权 HTTPS 网站访问。首次需要这一次授权；拒绝后原有托管搜索仍然可用。再打开输入框旁的「联网」按钮，模型便可按需要使用 `public_web.read_url`、`find_in_source` 和 `read_source`，无需逐个链接确认。关闭联网或增强读取后，新请求不提供这些工具。取消增强读取不自动撤销已授予的站点权限，可在 Edge 的扩展管理页调整。

公开读取由当前浏览器匿名访问 HTTPS 网址：不带站点 Cookie、Authorization 或来源页面信息，不读取其他标签页、登录页面资料或内网地址，不执行网页脚本，也不绕过验证码。网站能看到这些直接请求的网络地址；这与 OpenAI 托管搜索的访问路径不同。仅支持公共 HTTPS 域名和默认端口，拒绝本地/内网名称、IP 字面地址和携带凭据的网址；浏览器没有暴露目标域名的实际 DNS 地址，本工具不声称能检验所有 DNS 解析情况。重定向不自动跟随，以免从公共网址跳入本地地址；需使用经过核对的最终公开网址，或改用原有托管搜索。

HTML/纯文本最多下载 2 MB，PDF 最多 20 MB；单次读取超时 30 秒。PDF 文字提取最多 60 页/120000 字符，无 OCR。网页只提取静态正文，不保证完整展示动态页面。读取结果区分成功、部分内容、受限、超时、获取/解析失败、权限缺失和内部异常，保留实际可取得的状态；未知字段为 null。错误页、验证码、页面壳由有限的响应文字规则识别，并非完整的网页质量判定。失败/验证页面快照不会自动重试；需要再次尝试时，在设置中清空本对话快照后手动重发，请先确认网站允许访问。

每个对话独立保存最多 8 份、共 480000 个 UTF-16 字符的正文快照（不足空间时移除最旧快照）。每次新的读取尝试获得独立的 `public_` 编号与获取时间；默认重复读取复用本对话快照，不再次访问网站。`refresh=true` 仅对没有错误的已读快照创建新版本，旧编号保持原内容，直到清空或被移除。该编号与托管搜索内部来源编号不同，不能混用。精准查找只返回最多 8 个匹配片段，附存储范围内的匹配数量、字符位置和行号；分段读取最多 12000 字符，并提供 `next_offset`。已截断的快照不能代表全文。

设置中可「查看资料快照」、导出单份 TXT 或清空快照。清空只移除本地快照缓存，保留聊天、引用和已经发送给模型的上下文；如需删除这些本地资料，删除整个对话。清空或淘汰的编号返回明确错误，不默默下载新内容替代。快照预览最多 12000 字符，TXT 包含完整的已存内容和元数据；分享前请检查。停止生成会中断当前读取，不继续提交结果。一次回答最多 24 次增强工具调用、12 个模型轮次，最后一轮只允许根据现有资料回答；文件工具仍最多生成 10 个文件。

诊断 JSON 的 `calls` 仍只记录托管搜索实际暴露的元数据；新增 `local_calls` 记录增强读取的独立编号、原始/响应网址、实际 HTTP 状态、内容类型、失败阶段、截断、正文提取/返回长度、PDF 页数或匹配数等。`extracted_chars` 是截断前实际处理到的文字长度（PDF 仅已处理页），`prepared_output_chars` 是准备好的工具 JSON 长度，`submitted_output_chars` 仅表示该 JSON 已随后续 API 请求发出，不证明模型已接收或理解；`delivered_chars` 始终为 null。不记录完整网页正文或工具响应文本；缓存命中保留原获取时间。

## 联网诊断

设置 →「联网诊断」→「导出诊断 JSON」。新版默认记录开启联网后的新请求；旧请求无法补录，联网关闭或取消「记录联网请求的诊断信息」后不再记录。关闭记录不会关闭模型的搜索工具，已有记录仍可导出或单独清空。

记录仅在当前浏览器配置中保留最近 50 次 API 请求，最多 2 MB；一次回答中由文件工具触发的后续轮次分别记录，并通过本地 generation_id 关联。记录包括时间、模型/思考强度、请求 HTTP 状态、可取得的 x-request-id、response_id、联网工具调用编号/状态/操作、查询/网址/查找词、错误摘要和来源网址。不主动记录完整聊天、网页正文、附件、请求头或令牌；导出再次筛选字段并对常见凭据模式脱敏。查询、网址和错误摘要仍可能含隐私，分享前请检查。诊断不进入聊天上下文或 Markdown 对话导出。

接口未暴露的字段为 null；明确返回的空网址保留为空字符串。批量查询和来源保留在同一工具调用中，不猜测每条查询的结果对应关系。来源 display_number 只是侧栏展示编号，不是模型内部的来源 ID。API 的 HTTP 状态不是网页的 HTTP 状态，工具 completed 不证明已读到有效正文；工具失败可以与整体回答完成并存。started 表示尚未观察到终止事件，可能仍在进行或已中断，不能由日志反推服务器是否还在运行。

## 安装

1. 下载本仓库源码 ZIP 并解压，或使用 Git 克隆。
2. 打开 `edge://extensions/`，开启「开发人员模式」。
3. 点击「加载解压缩的扩展」，选择解压后的 **`extension` 文件夹**。
4. 在 Edge 工具栏点击扩展图标，打开侧栏。
5. 打开设置，点击 **Continue with ChatGPT**，亲自在 OpenAI 官方页面完成登录和授权。
6. 返回侧栏，点击「刷新模型」，选择模型并发送测试问题。

运行扩展无需 Node.js、本地辅助程序或 Codex。Windows 用户也可以运行「打开手动安装入口.cmd」打开扩展管理页和目录。

更新已有安装：替换文件后，在 `edge://extensions/` 点击「重新加载」，关闭并重新打开侧栏。无需卸载；卸载会删除扩展的本地记录。

若登录反复出现人机验证，请停止重复尝试，并手动确认同一浏览器能否登录 ChatGPT 官网。不要使用自动化测试配置进行真实账号登录。

## 使用资料和文件

输入框上方的「联网：关/开」按钮允许或关闭 OpenAI 托管的 `web_search` 工具。开关保存在当前浏览器配置，默认关闭；开启后授予完整的公共联网检索许可，模型可自主搜索、打开公共页面、页面内查找并连续检索，无需逐次询问许可，不强制每条消息联网。关闭后，新请求不提供搜索工具，已有引用仍保留。回答下方的来源列表默认折叠，点击标题可展开；重新打开侧栏或切换会话后恢复折叠，Markdown 导出仍包含来源。

原来的本地资料规则仅约束用户浏览器页面和截图，不限制已开启的公共联网操作。提供公共 URL 请求读取时，不会自动读取无关的当前标签页。模型应区分搜索摘要、有效正文、空返回和错误页面，不得仅凭调用完成就声称已核实；提示词不能保证每次回答都完全遵守，需要结合真实工具记录判断。

联网不授予读取浏览器标签页、截图或文件的权限；这些仍需明确读取/查看指令或相应按钮。搜索能否实际使用取决于模型、账号和工作区策略。如服务拒绝搜索，侧栏显示错误，用户可关闭联网或切换模型后手动重发，不自动重试。搜索查询可能包含与问题有关的聊天信息，由 OpenAI 服务处理。联网结果中的文字作为资料，不作为插件指令执行。

选文、上传、粘贴或按钮读取的资料先进入草稿，可移除，发送后才交给模型。明确说「读一下当前网页」或「看一下左边这篇论文」也可触发资料读取；一般聊天不触发。

网页读取可能需要授权当前站点。截图前可能需要在该网页点击一次扩展图标，以授予临时访问权限。浏览器内部页和本地 PDF 请使用上传；加密 PDF 需先解锁。仅支持列出的图片和文本格式，不支持直接读取 Word/Excel。

历史导出包含聊天文字、公式、联网引用/来源和生成文件的名称；生成文件内容需点击附件单独下载，图片不会嵌入 Markdown 导出。

## 登录与服务边界

本扩展采用官方授权端点、PKCE 和身份签名验证，不读取 ChatGPT 官网 Cookie、Codex 凭据或密码。请求使用已授权的 ChatGPT 套餐额度，不与官网聊天历史同步；可用模型与额度取决于账号和服务权限。

**当前回调接收方式是工程适配：** 扩展观察登录标签页导航到 `http://127.0.0.1:1455/auth/callback`，不启动本地 HTTP 监听器。官方文档中的本地回调流程依赖监听器，因此不能将本实现描述成 OpenAI 官方支持的浏览器扩展登录方式。

维护者已手动验证账号登录、真实回答、右键选文与侧栏显示；跨账号发行兼容性、授权刷新及所有资料/工具的真实服务行为尚未完整验证。服务端接口、预览资格和授权行为可能变化，登录或请求可能因此失效。

断开后重新登录默认复用原应用登记，避免反复新增同名应用。设置中可选择已登记账号；只有连接其他账号或工作区时才选“新登记”。已有登录信息会自动迁移登记编号，令牌存储和自动登录方式保持不变。清空扩展数据、卸载或换浏览器配置后，可能需要新登记；已撤销的登记不会自动回退为新登记。此修复不能合并服务端已有的重复项。

授权、聊天和附件存储没有使用操作系统凭据库加密。「断开」只移除本机授权；服务端撤销请在 ChatGPT 设置中操作。详见 [PRIVACY.md](PRIVACY.md)。

官方参考：[注册与登录](https://developers.openai.com/siwc/token-sharing-open-source/sign-in)、[模型与推理](https://developers.openai.com/siwc/token-sharing-open-source/models-and-inference)、[预览限制](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations)。这些文档不代表对本项目的认可或兼容性保证。

## 开发与验证

需要 Node.js 22 或更新版本：

```sh
npm ci
npm test
npm run package
```

`npm test` 覆盖授权登记复用、账号隔离、聊天和联网引用处理，不需要真实账号。构建产物是 `dist/gpt-sidebar-0.4.0.zip`，仅含扩展运行文件与许可说明。

Windows 中安装 Microsoft Edge 后运行 `npm run test:browser`。可通过环境变量 `EDGE_EXECUTABLE_PATH` 指定浏览器路径。测试使用独立临时配置、模拟模型请求和测试素材，不接触日常浏览器账号。

已有 Edge 检查覆盖侧栏调用、草稿和历史、语言与主题、公式渲染、模拟文件工具、PDF 提取、图片粘贴/拖放、停止和中断恢复，以及联网开关、流式引用、来源导出和不自动重试。模拟请求通过不代表真实服务的全部行为已验证。贡献要求见 [CONTRIBUTING.md](CONTRIBUTING.md)。
